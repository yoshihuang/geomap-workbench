# 地質圖判釋工作台

構造地質判釋與作圖工具：地質圖判釋、任意剖面、3D 地質模型。整個工具是單一個 `index.html`，在瀏覽器裡執行，資料不會上傳到伺服器。

**線上使用：** https://yoshihuang.github.io/geomap-workbench/

## 功能

- **內建範例**：水平、傾斜、褶皺、斷層、不整合、侵入體等構造案例，附判釋步驟與練習模式。
- **地質圖判釋**：查詢地層與位態、三點法、構造等高線／等深線、層理統計（下半球等面積投影）、地質史排序。
- **地質剖面**：在地圖上畫任意折線剖面，可調垂直誇張，顯示視傾角與軸面跡線。
- **3D 地質模型**：地塊、斷層面、地層界面、圍籬圖，可切除四周並擷取畫面。
- **匯入 QGIS GeoPackage（.gpkg）**：自動讀取地質區、斷層、等高線／高程點、層理位態、鑽孔與剖面線圖層，推定地層新老、不整合與厚度並建模。
- **下載範例 GeoPackage**：由內建範例產生含 QGIS 樣式的 .gpkg，可作為整理自己資料的範本。每個範例都輸出相同的 11 個圖層：`geology`、`aureole`（接觸變質帶）、`subcrop`（潛露圖）、`faults`、`fold_axes`（褶皺軸跡）、`fold_domes`（穹窿與盆地）、`contours`、`bedding`、`cleavage`（軸面劈理）、`boreholes`、`section_line`；範例中沒有的圖徵保留為空圖層。
- **位相檢核**：地質區與潛露圖的多邊形由共用邊界組成，輸出前會檢核無重疊、無縫隙、無自我相交且完整覆蓋圖幅，未通過就不輸出。
- 介面語言：繁體中文、简体中文、English、日本語。

## GeoPackage 資料需求

- 地質區多邊形（必要），含地層代號欄位。
- 選用：斷層線、等高線（高程欄位）或高程點、層理位態點（傾角與傾向或走向）、鑽孔、剖面線。
- 選用欄位 `strat_order`（1＝最老）、`series`（不整合以上為較大數字）、`thick_m`、`kind`（sed／ign）若有填寫會直接採用。
- 請使用投影座標（公尺）；經緯度會自動近似換算。

## 本機使用

直接用瀏覽器開啟 `index.html` 即可。需要網路連線以載入字型與 CDN 套件（three.js、sql.js、fflate、opencc-js）。
